Как заполнить файл

Лист должен называться База знаний. В первой строке — названия столбцов. Ниже — один вопрос и один ответ в каждой строке. Используйте обычный текст, без формул и объединённых ячеек.

ТемаВопросОтвет
ПарковкаКак оплатить парковку?Утверждённая инструкция по оплате или ссылка на неё.
НавигацияГде посмотреть схему аэропорта?Утверждённая ссылка на схему аэропорта.

Это пример структуры. В скачанном шаблоне нет готовых ответов — заполните его своими.

Обязательно: заполнить тему и вопрос. Ответ можно оставить пустым для последующего редактирования, но такую карточку нельзя опубликовать.

Для темы используйте короткое название, например «Багаж и ручная кладь» или «Парковка и транспорт». Перечислять все разделы через разделитель не нужно.

Необязательные столбцы и повторная загрузка
  • Код — постоянный уникальный код карточки, например parking_payment. При повторной загрузке тот же код будет пропущен даже после переименования файла или перестановки строк. Код должен быть уникальным для всей базы.
  • Другие формулировки — варианты вопроса, каждый с новой строки внутри одной ячейки.
  • Условия — когда подходит этот ответ.

Если код не задан, карточка определяется по сочетанию темы и вопроса. Изменение темы или вопроса создаст новую карточку. Повторная загрузка не обновляет существующие ответы: редактируйте их в админке, где сохраняется история версий.

Допускается до 5000 строк на листе. Файлы .xls, .csv и .xlsm не поддерживаются — сохраните их как .xlsx.

Исходный формат заказчика тоже поддерживается

Обязательный лист Обновл. таблица: первая строка — заголовок; столбец A — тема или подраздел, B — вопрос, C — ответ. Строка только с A задаёт раздел. Объединённые вопросы в B сохраняются с вариантами ответов и пометкой для проверки.

Необязательные листы: КОВЕР ответы (A — вопрос, B — ответ) и Полезные контакты (первая строка — заголовок, A — название, B — контакт). Контакты загружаются как внутренние записи.

Для этого старого формата совпадение определяется по имени файла, листу и номеру строки. Не переставляйте строки для обновления: существующие записи не перезаписываются, а переименование файла может создать дубли. Для новых загрузок удобнее использовать шаблон выше. Если в файле есть лист «База знаний», импортируется только он.
